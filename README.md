# NÓRD · tienda de demostración

Catálogo de ropa, accesorios y fragancias de ejemplo, con modo oscuro y diseño adaptable. No es una oferta comercial real.

Este repositorio contiene la demostración estática para GitHub Pages y **nord-proyecto.zip**, con el código fuente completo de la aplicación React, servidor, base de datos, imágenes, migraciones y pruebas. Los archivos de la aplicación conservan sus carpetas dentro del ZIP. Descárgalo y descomprímelo antes de ejecutar los comandos del README incluido.

La demostración permite filtrar productos, ver variantes y probar el carrito. No recibe pedidos reales, no solicita datos personales ni ejecuta un panel administrativo. GitHub Pages no ejecuta el servidor de inventario y reservas. El enlace a la tienda completa requiere el acceso privado del alojamiento durante la preparación.

La aplicación completa implementa inventario guardado, propuestas de actualización con confirmación, auditoría, reservas atómicas, cancelaciones y vencimiento, permisos de administrador y proveedor, y acceso por código temporal de correo. El envío real requiere configurar Resend, un remitente verificado y los contactos del negocio. También requiere programar mantenimiento y completar los datos del operador antes de vender. La integración con IA es opcional.

Se aprobaron 20 pruebas automatizadas y las comprobaciones HTTP locales de existencias simultáneas y cancelación. La entrega real de correos está pendiente. Las políticas son borradores para El Salvador; requieren revisión de la operación real. La revisión visual formal contra la composición original permanece abierta; no se certifica una reproducción exacta ni que la tienda esté lista para comercio real.

**GUIA.md** contiene la configuración y las limitaciones. **image-credits.html** documenta las fuentes y licencias de las fotografías. Las imágenes, marcas, precios, cantidades y contactos son ejemplos. No hay afiliación con las marcas mostradas. No se incluyen contraseñas, claves, sesiones ni bases con pedidos de prueba.

La copia independiente es `index.html`: incluye las imágenes y fuente, y puede abrirse sin conexión. Las políticas se abren como contenido incorporado cuando se usa como archivo local.
